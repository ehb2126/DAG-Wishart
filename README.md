# DAG-Wishart

This repository contains the paper and supporting materials for
**High dimensional Bayesian inference for Gaussian directed acyclic graph
models** by Emanuel Ben-David, Tianxi Li, Hélène Massam, and Bala Rajaratnam.

## Current corrected working preprint

Version 6.2 (August 2026) is available under [`paper/v6.2`](paper/v6.2/).
This release includes:

- a compiled 51-page PDF;
- complete LaTeX source and the two numerical-figure assets required to build it;
- native TikZ source for every DAG in the paper;
- an independent numerical validation script and validation reports.
